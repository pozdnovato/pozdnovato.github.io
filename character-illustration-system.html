Character Illustration System for Tempo Software

Tempo Software is a B2B SaaS company in the Atlassian ecosystem. Illustration has historically been part of the company’s brand identity, used to draw attention to marketing campaigns. Previously, every illustration was created from scratch by hand. This required specialized skills from designers, took a lot of time, the output was inconsistent across materials.

I built a modular illustration system: a library of reusable illustrations plus a detailed guide for creating new scenes, so any designer can assemble channel-ready visuals fast while keeping one visual language.

Task

As part of the company’s visual identity update, I needed to solve two challenges: develop a fresh, distinctive character illustration style, and build a flexible system that makes producing new characters within the same visual language easy.

The new style had to move past the limitations of the old approach and better reflect the brand’s strategy: to be open, modern, dynamic, accessible and inclusive, energetic and fun.

Process

The new style had to move past the limitations of the old approach and better reflect the brand’s strategy: to be open, modern, dynamic, accessible and inclusive, energetic and fun.

The characters’ anatomy stays close to human, but slightly modified to make the style more unique and recognizable. The system is built to represent different communities, cultures, body types, and appearances. The audience now can recognize themselves in the brand’s communication, and the illustrations read as inclusive and relatable.

To keep new characters consistent and quick to produce, I introduced a clear set of restrictions: a limited color palette and gradients, restricted outlines, no perspective, and characters shown only front-facing or slightly turned. The system is based on three body types and two gender presentations. I documented all of it in a detailed illustration guideline.

Result

The result is a structured illustration system with a distinctive character style, clear visual rules, and enough flexibility to create diverse, expressive characters.

It includes a large library of ready-to-use characters and a guideline for building new ones. It’s making the style scalable and practical for everyday design work, and consistent across formats and teams.

Marketing production dropped from days to hours, and the work is no longer tied to a single illustrator. Any designer on the team assembles channel-ready scenes from existing components instead of drawing each one from scratch.

One visual language now runs across every channel, so the brand reads consistently from a banner to a deck to an onboarding screen without manual review on each asset.

The system works across a wide range of brand materials: website banners, landing pages, email campaigns, social media, presentations, print, product communications, event graphics, onboarding flows, and internal documents.

A ready-made library plus a clear creation process speeds up adapting illustrations for different channels and formats, and lets designers expand the system without losing consistency or quality.
